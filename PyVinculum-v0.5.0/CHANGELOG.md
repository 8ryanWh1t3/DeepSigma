# Changelog

## 0.5.0 — P↔D Tension Engine

- Reset VINCULUM to its original scope: measure P versus D, not governance/authority.
- Added universal `ΣV={P,D,V,τ,Coverage}` output.
- Added 0–100 VINCULUM score, effective tension, and coverage-damped usable value.
- Added asymmetric language P→D and mathematics D←P scoring models.
- Added explicit named P/D driver rules and configurable scoring.
- Added recursive weighted aggregation for documents, episodes, datasets, TTL graphs, and corpora.
- Added RDF/Turtle parsing and per-triple scoring through rdflib.
- Added structured-data scoring.
- Added CLI and examples for claims, documents, episodes, math, and TTL.
- Added narrow v0.4 migration shim; governance-heavy behavior is no longer core.
