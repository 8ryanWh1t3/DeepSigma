# v0.2 → v0.3 Migration

v0.3 is additive for the principal v0.2 terms. Existing core/evidence/authority/lifecycle/memory terms retain their IRIs.

Notable change: literal `doo:expectedOutcome` remains available but is deprecated. New implementations should use `doo:ExpectedOutcome` plus `doo:anticipatesOutcome` so expected outcomes are addressable objects with their own identity and provenance.

Lifecycle individuals keep their existing IRIs and now also participate in SKOS concept schemes. `doo:Committed` is restored from v0.1.

Validation is now profile-specific. Import the shape graphs matching the conformance level you claim.
