Read these results in context

    How to record a fair comparison

    Use comparable cases, the same observation window, and a consistent definition of completion. Record all costs, including data collection, within nonoverlapping effort categories. Effort is the sum of person-minutes across people; elapsed time is wall-clock time from intake to closure or the observation cutoff.

    Each case compares a baseline run with a CERPA run. Only decisions closed, supported, and authorized in both arms enter paired timing. Every case remains in effort and count measures. An observed difference does not establish causation.

    The template contains zeros and false flags as placeholders and is marked illustrative. Replace every value with your measurements, then change data_kind to observed before interpreting results. The tool does not inspect evidence, make authorization decisions, or produce a combined efficiency score.
