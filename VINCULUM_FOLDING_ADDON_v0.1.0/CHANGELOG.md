# Changelog

## 0.1.0 — Navigable Fold

Initial additive release. Introduces strict episode snapshots, TIME/WORDS/NUMBERS,
explicit folds and counterfolds, all four JIT lenses, source evidence metadata,
read-only view/unfold projections, version-pinned cross-episode navigation,
replayable return paths, local SQLite snapshots, exact host capture, draft review
handoffs and portable verified export bundles. No existing VINCULUM kernel is
changed. Real-host integration remains an explicit uncompleted validation gate
in the recorded build environment.
