# Scope Lock — VINCULUM v0.5.x

**VINCULUM is for when words and numbers collide.**

Core responsibilities:

```text
WORDS → numeric expectation
NUMBERS → observed numeric state
SECOND ORDER → strength of semantic determinization and numeric defense
VINCULUM → measurable collision / third state
```

v0.5.2 explicitly models:

```text
P_L → D_L  with S_L
D_M ← P_M  with R_D and U_D
```

Out of scope: governance, authorization, approval, command action, Policy Fence behavior, and truth adjudication.
