# Changelog

## 0.1.0 — 2026-10-03

Initial executable Cartography add-on. Introduces typed immutable maps; explicit predicate legend;
time-bound views; deterministic path/dependency/impact traversal; structural findings; reversible
folding; edition diffs and SQLite archives; native MemoryGraph import; native-shaped CERPA drafts;
proposed read-only VINCULUM interchange; JSON/JSONL/CSV/RDF exports; optional workbook export; CLI;
synthetic demo; tests and verification evidence. Existing Deep Sigma and VINCULUM kernels are not changed.
