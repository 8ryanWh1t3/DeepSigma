# Changelog

## 0.6.0 — 2026-10-02

Cross-order, pair-specific hinge and codec extension from the verified 0.5.2 package.

Added typed order-aware representations on both language and mathematics sides; independent P/D channels; arbitrary higher-order factors; pair-local HingeOrderState; sparse cross-order matrix; strict identity/quantity/scope/time compatibility; exact rational units and interval comparisons; explicit raw-versus-supported discrepancy; dependency lineage; hierarchical aggregation; bounded pairing monitor; source/target codec audit; JSON/Turtle scenarios; generic RDF field mapping; portable reports; optional XLSX; non-scored narrative context; plugin protocol; and a separate `vinculum-lattice` CLI.

Corrected new-path semantics: equal P/D balance is not conflict; a number does not imply full support; non-comparability is not disagreement; uncertainty does not erase delta; missing comparisons do not become zeros; no automatic authority or action is inferred.

Preserved the original functional 0.5.2 modules and tests. Legacy object scoring is still available and explicitly separate from the new contract. No intermediate v2.0 package is claimed.
